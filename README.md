# Week 04 - Automated Testing

## Mục tiêu
Thực hiện bài kiểm thử tự động đầu tiên bằng Selenium và pytest.

## Công cụ
- Python 3.14.0
- Selenium
- pytest
- Visual Studio Code
- Google Chrome

## Cách chạy
py -m pytest -v test_smoke.py

## Kết quả
Kiểm thử tự động mở trình duyệt và kiểm tra tiêu đề trang web.
