## 🚀 Hướng dẫn thực thi

### 1. Chạy riêng bài làm của Thành viên 5 (TC13 - TC15)
```bash
python thanh_vien_5.py
```

### 2. Chạy kiểm thử tổng hợp 15 Test Cases & Xuất báo cáo (Nhiệm vụ Thành viên 5)
```bash
python run_all.py
```

### 3. Mở báo cáo trực quan
- Mở file `BAO_CAO_TONG_HOP.html` bằng trình duyệt để xem giao diện Dashboard báo cáo đẹp mắt và click xem ảnh chụp màn hình minh chứng.
- Đọc file `HUONG_DAN_CHI_TIET.md` để nắm vững lý thuyết, giải thích từng dòng lệnh và kịch bản thuyết trình trên Slide 6 & 7.
