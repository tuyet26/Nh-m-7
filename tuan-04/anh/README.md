# Thư mục ảnh chụp màn hình

Mỗi thành viên chụp ảnh màn hình kết quả chạy test thành công trên máy của mình và đặt vào thư mục này.

## Quy tắc đặt tên file ảnh

- `nguyen_minh_tuan.png`
- `do_trung_hieu.png`
- `dang_thanh_nam.png`
- `luu_thi_tuyet.png`
- `do_dinh_viet.png`

## Cách chụp ảnh màn hình

- **Windows**: Nhấn `Win + Shift + S` hoặc dùng Snipping Tool
- **macOS**: Nhấn `Cmd + Shift + 4`
- **Linux**: Nhấn `PrtSc` hoặc dùng Screenshot tool

Ảnh cần thể hiện rõ: tên file test, kết quả PASSED, và số lượng test đã chạy.
